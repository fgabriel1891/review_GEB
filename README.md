# FTA notebook for GitHub Pages

This folder contains the rendered main notebook and its local figures and interactive assets. Publish the contents of this folder as the root of a GitHub Pages site; open `index.html` to preview it locally.

The included HTML is the saved render from 23 November 2026. The notebook was edited afterwards, so render the main notebook again to include the latest changes before publication. Rendering runs any notebook chunks whose analysis switches are enabled: review those switches first.

To refresh this folder after rendering, run `refresh.ps1` from PowerShell. It copies the latest saved HTML, its Quarto assets, and the three figures referenced outside the notebook assets folder. Review the updated page before publishing.
